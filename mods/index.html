Mods & Replacements

Fields of Mistria supports mods through Steam Workshop and manual loading. This beginner walkthrough shows the safe path: back up saves, install one mod at a time, restart the launcher, and avoid silent overwrites.

How to install a mod safely

Total time: 10 minutes including the backup. The right order is the one that lets you undo a broken mod without losing saves.

Step 1: Back up your save

Critical. Before subscribing to any mod:

  1. In Steam, right-click Fields of Mistria → Manage → Browse Local Files.
  2. Open the Saves folder and copy it to a safe place on your desktop or cloud storage.
  3. Label it with today's date: e.g. Mistria-save-2026-08-26.zip.

Step 2: Install one mod at a time

Open Steam Workshop, search Fields of Mistria, and subscribe to a single mod. Common beginner picks:

  • UI Tweaks — resizable text and HUD elements.
  • Crop Reskin — replacement crops that fit alternate art styles.
  • NPC Portrait Pack — different dialogue portraits, for slightly-more-animated feeling.
  • Map Overlays — farmland markers for content creators.

Always subscribe to a single mod first. Re-launch the game before subscribing to another.

Step 3: Verify the mod loaded

Launch the game, load your save, and check:

  • The UI or visual change you expected
  • No errors on the main menu
  • Save still loads with no warnings

If anything is wrong, unsubscribe in Steam Workshop, restore your save from the backup, and try a different mod. Most issues are caused by mods loading out of order — switching the load order (via the Mod Manager menu) usually fixes it.

Patch-sensitive mods

Patch 0.13.x changed how the breeding GUI works. Some 0.11.x mods may need an update before they work in 0.13.x. Watch the mod's Workshop page for version pins. If a mod hasn't been updated since 0.11.x, expect breakage.

Manually loading a mod

If you find a mod outside the Workshop (e.g. from a community Discord or a Patreon):

  1. Unzip it into AppData/Local/Fields_of_Mistria/Mods/<name>/ (Windows) or the equivalent macOS path.
  2. Re-launch the game so the mod folder is read.
  3. Verify the same as Workshop mods.

Manually loaded mods are not auto-updated. You have to re-download them when a new patch lands.

FAQ

Will mods break my save?

Backup first, and they generally won't. If they do, restoring the save folder reverts cleanly.

Can I play with friends using mods?

The current build is single-player. Mod compatibility for the announced co-op mode is "TBD" on the developer's roadmap.

Is modding safe for achievements?

Some mods disable achievements. Check the mod description before subscribing if you care about the achievement sheet.

Heads up: Mods go stale between patches. Always check the mod's last-updated date and patch-pin comment before subscribing. A stale mod can soft-lock your breeding GUI or other mid-patch content.
